# 课堂规则（中文模式）

> 第 1 天下午第 1 步，Codex 会把这些规则写进这个项目的 `AGENTS.md`（Codex 读取项目规则的文件）。选中文模式的同学用这一份；选英文模式的同学请用 [house-rules.md](house-rules.md)，`AGENTS.md` 里只写英文。

## 请这样跟我沟通

- 我是做生意的，不是技术背景的人。**请尽量不要用技术术语。**
- 如果真的需要用到技术名词，请先用一句简单的话解释它是什么。
- 请用简单的中文回复我，常用的英文词（例如 Desktop App、folder、login）可以保留。
- 技术上的选择（用哪个 library、哪个 database）请你帮我决定，然后用一句话告诉我你选了什么、为什么。
- 汇报进度时，请告诉我「现在可以做什么了」，不用列出改了哪些文件或 function。
- 每完成一步，请告诉我：打开哪个网址、点哪里、应该会看到什么。

## 技术栈

- **Next.js（App Router）** + **TypeScript**
- 样式用 **Tailwind**；组件优先用 `src/components/ui/` 里现成的 shadcn/ui
- **Mobile-first responsive web**：先做手机版面，再调整电脑版（用 Tailwind responsive classes），因为很多同事是用手机看的
- 图表用 **recharts**（已经装好）
- 所有数据读写都通过 `src/lib/followups.ts` 里的 `store`
- ⚠️ 这是 **Next.js 16**（比较新），有些写法和网上旧的教程不一样。不确定时，请以项目里现有的写法为准。

## 做事的约定

- 只改需要改的文件，请不要顺手改其他东西
- 不确定我要什么时，请直接问我，不要自己猜着做下去

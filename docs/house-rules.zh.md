# 课堂规则（中文模式）

选中文模式的同学用这一份；选英文模式的同学请用 [house-rules.md](house-rules.md)。课堂规则分两部分：

1. **沟通方式**：第 1 天一开课，就贴进 Codex desktop app 里。之后所有 Codex chats 都会照着做，你也随时知道去哪里查看和修改。
2. **项目规则**：已经写好了，中文版在 [`AGENTS.zh.md`](AGENTS.zh.md)。Codex 读取的是项目里的 `AGENTS.md`（Codex 读取项目规则的文件），所以上课时要先换成中文版，然后你只需要填一小段关于你生意的介绍。

## 第 1 部分：沟通方式（第 1 天一开课）

1. 在 Codex desktop app 打开 **Settings**（Mac：Cmd+, · Windows：Ctrl+,）> **Personalization** > **Codex instructions**。
2. 复制下面的规则，贴进那个框里。如果框里已经有你想保留的内容，就贴在下面。然后保存。

```text
- 我是做生意的，不是技术背景的人。请尽量不要用技术术语。
- 如果真的需要用到技术名词，请先用一句简单的话解释它是什么。
- 请用简单的中文回复我，常用的英文词（例如 Desktop App、folder、login）可以保留。
- 技术上的选择（用哪个 library、哪个 database）请你帮我决定，然后用一句话告诉我你选了什么、为什么。
- 汇报进度时，请告诉我「现在可以做什么了」，不用列出改了哪些文件或 function。
- 每完成一步，请告诉我：打开哪个网址、点哪里、应该会看到什么。
```

以后想改，随时回到同一个地方修改就可以了。这些规则适用于所有 Codex chats；项目的 `AGENTS.md` 会加上项目规则，如果有冲突，就以项目的规则为准。

可选：如果你也希望平常的 ChatGPT chats 保持相同的沟通方式，可以把这些规则另外贴进 chatgpt.com > Settings > Personalization > Custom instructions。

## 第 2 部分：项目规则（已经帮你写好了）

项目规则已经写好了：用简单的话说明、一小步一小步来、删除或覆盖文件前先问你、你的生意数据只留在你的电脑里。`class-starter` folder 里的 `AGENTS.md` 是英文版，中文版在 [`docs/AGENTS.zh.md`](AGENTS.zh.md)。

上课时请这样做：

1. 在 Codex 里输入：「请用 docs/AGENTS.zh.md 的内容覆盖 AGENTS.md。」Codex 会先问你确认，回答「好」就可以了。
2. 打开 `AGENTS.md`，把最上面 **关于我的生意** 里的每个 `<待填>` 换成一两句话：你的名字、你的生意是做什么的、你平时用到的数据文件、做出来的东西给谁看。
3. 保存。

有哪一项没填也没关系，Codex 开始动手之前，会一次问你一个问题，帮你补上。

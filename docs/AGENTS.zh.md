# 给 Codex 的项目规则

Codex 每次在这个项目里工作，都会先读这份文件。下面的课堂规则已经帮你写好了，你只需要填 **关于我的生意** 这一部分就可以了。

## 关于我的生意

<!-- 同学们：请把每个 <待填> 换成一两句简短的话，用平常的说法就可以了。 -->

- **我的名字**：<待填>
- **我的生意是做什么的**：<待填，例如「我在 Shopee 和 Facebook 卖婴儿衣服」>
- **我平时用到的数据文件**：<待填，例如「Shopee 的销售记录和 Facebook ads 报告，都是 CSV 文件」>
- **做出来的东西是给谁看的**：<待填，例如「我的 3 位客服同事，他们大多用手机看」>

开始任何工作之前，请先看这一部分。如果上面还有 `<待填>`，请先不要写 code：麻烦一次问我一个问题，把我的回答填进去，再给我看一下确认。

## 和我合作的方式

- 我是做生意的，不是写程序的人。请用简单易懂的话，每一步用一两句话说明就好。
- 请一小步一小步来。每完成一步，请告诉我：现在可以做什么了、要打开哪里或点哪里、应该会看到什么。
- 不确定我要什么时，请直接问我一个简短的问题，不要自己猜。
- 只改这一步需要改的文件，请不要顺手整理或改写其他东西。
- 每个任务尽量小而集中，让我的 ChatGPT plan 用量可以撑完整堂课。

## 请先问过我

- 删除、覆盖、改名或移动任何我做的或我给你的文件之前（特别是 `data/` 里的文件），请先告诉我是哪个文件、为什么，等我说好再做。
- 安装新的工具或 package 之前。
- Push 到 GitHub、发布、deploy 或把任何东西分享到网上之前。

## 我的数据留在我的电脑里

- 我的生意文件（销售、客户、广告）只留在这台电脑上。请不要上传、不要传到网上的服务，也不要贴到任何网站。
- 请不要把真实的客户名字、电话或地址写进 code、例子或截图里，请用虚构的例子代替。
- 请不要叫我把密码或 login key 贴进对话里。如果需要，请告诉我自己要放在哪里。
- `data/` 里的示范文件可以放心拿来练习。

## 技术栈

- **Next.js（App Router）** + **TypeScript**
- 样式用 **Tailwind**；组件优先用 `src/components/ui/` 里现成的 shadcn/ui
- **Mobile-first**：先做手机版面，再调整电脑版，因为很多人是用手机看的
- 图表用 **recharts**（已经装好）
- 所有数据读写都通过 `src/lib/followups.ts` 里的 `store`；数据保存在这台电脑的浏览器里
- 这是 **Next.js 16**，有些写法和网上旧的教程不一样。不确定时，请以项目里现有的写法为准。
